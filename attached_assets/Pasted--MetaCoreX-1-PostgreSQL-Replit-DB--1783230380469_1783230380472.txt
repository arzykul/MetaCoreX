Создай полноценную систему задач для агентов MetaCoreX.

**1. БАЗА ДАННЫХ (PostgreSQL / Replit DB):**

Создай таблицу `tasks`:
- id: VARCHAR(36) PRIMARY KEY (UUID)
- title: TEXT NOT NULL
- description: TEXT
- reward: DECIMAL(20,2) NOT NULL (в ARZY-G)
- status: VARCHAR(20) DEFAULT 'pending' (pending | assigned | completed | verified | cancelled)
- agent_address: VARCHAR(42) (адрес агента, кто взял задачу)
- created_by: VARCHAR(42) NOT NULL (кто создал)
- proof: TEXT (доказательство выполнения)
- assigned_at: TIMESTAMP
- completed_at: TIMESTAMP
- verified_at: TIMESTAMP
- created_at: TIMESTAMP DEFAULT NOW()

Создай таблицу `task_history` для аудита:
- id: SERIAL PRIMARY KEY
- task_id: VARCHAR(36) REFERENCES tasks(id)
- action: VARCHAR(20) (created | assigned | completed | verified | cancelled)
- actor: VARCHAR(42)
- timestamp: TIMESTAMP DEFAULT NOW()

**3. ЛОГИКА РАБОТЫ:**

При создании задачи:
- Проверка: reward > 0
- Сохраняем в БД со статусом 'pending'

При взятии задачи:
- Проверка: статус 'pending'
- Проверка: агент зарегистрирован (проверяем контракт)
- Обновляем статус на 'assigned'
- Записываем agent_address и assigned_at

При завершении задачи:
- Проверка: статус 'assigned'
- Проверка: агент == agent_address
- Проверка: proof не пустой
- Обновляем статус на 'completed'
- Сохраняем proof и completed_at
- Вызываем submitProof в контракте
- Награда отправляется агенту через контракт

При верификации (админ):
- Проверка: статус 'completed'
- Обновляем статус на 'verified'
- Награда уже выплачена, просто маркируем как верифицированную

**4. ИНТЕГРАЦИЯ СО СМАРТ-КОНТРАКТОМ:**

При завершении задачи:
1. Вызываем contract.submitProof(proof, task.reward, 8)
2. Получаем reward = (task.reward * 8) / 10
3. Показываем агенту: "Задача выполнена! Награда: X ARZY-G"
