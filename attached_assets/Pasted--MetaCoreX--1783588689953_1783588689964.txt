Создай систему тестнет-аирдропа для MetaCoreX, чтобы стимулировать ранних пользователей регистрировать агентов и отправлять proof.

## 1. База данных (PostgreSQL)

Добавь таблицу `airdrop_points`:
- id (UUID, PRIMARY KEY)
- wallet_address (VARCHAR(42), NOT NULL, UNIQUE)
- total_points (INTEGER, DEFAULT 0)
- agent_registered (BOOLEAN, DEFAULT FALSE)
- proofs_count (INTEGER, DEFAULT 0)
- referral_code (VARCHAR(20), UNIQUE)
- referred_by (VARCHAR(42), REFERENCES wallet_address)
- last_updated (TIMESTAMP, DEFAULT NOW())

## 2. Логика начисления баллов

- За регистрацию агента: +100 баллов (при вызове /api/agents/register)
- За каждый отправленный proof (submitProof): +50 баллов
- За привлечение друга (реферал): +200 баллов, если друг зарегистрировал агента

Начисление должно происходить автоматически через существующие API-эндпоинты (добавить вызов updatePoints).

## 3. API эндпоинты

- GET /api/airdrop/points/:address — получить баллы пользователя
- GET /api/airdrop/leaderboard — топ-10 пользователей по баллам
- POST /api/airdrop/referral — создать реферальный код (автоматически при регистрации агента)
- POST /api/airdrop/claim — заглушка (вернёт сообщение, что токены будут распределены после Mainnet)

## 4. Страница на сайте /airdrop

Добавь страницу, которая показывает:
- Текущие баллы пользователя (после подключения кошелька)
- Количество зарегистрированных агентов
- Количество отправленных proof
- Реферальную ссылку
- Топ-лист (leaderboard)
- Прогресс-бар: сколько баллов до следующего уровня (например, 500, 1000, 5000)

Стиль: белый фон, синий акцент, минималистичный, как у остальных страниц.

## 5. Ретроспективное начисление

При первом запуске системы (в отдельном скрипте) просканируй существующих агентов и их proof (из таблиц agent_tasks или напрямую из events) и начисли баллы за прошлые действия, чтобы ранние пользователи не остались без награды.
